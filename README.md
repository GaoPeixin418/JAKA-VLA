# 双臂 VLA 事件感知重规划实验

项目目录：`/data/jaka-vla`。当前使用 ALOHA-AgileX 仿真机器人，尚未适配节卡真机。

## 环境

- 服务器：RTX 4090 24GB，约60GB系统内存；150GB独立数据盘。
- `envs/robotwin`：Python 3.10，RoboTwin/SAPIEN/cuRobo。
- `envs/vla`：Python 3.12，LeRobot v0.4.4 / SmolVLA，复用预装PyTorch 2.8 CUDA 12.8。
- 每次运行前 `source /data/jaka-vla/env.sh`，再激活所需环境。
- 仿真环境、模型环境隔离；不修改服务器预装base环境。

## 首个里程碑

1. 验证CUDA计算和实际无界面RGB渲染。
2. 用脚本专家生成handover_block的少量三相机示教。
3. 转为LeRobot数据，验证状态、动作、RGB顺序及采样频率。
4. 完成SmolVLA小规模训练与保存/重载检查。
5. 再扩大示教集，比较固定执行长度K的闭环成功率和推理开销。

专家轨迹成功不等于学习策略成功。训练损失下降不等于闭环任务成功。
后续所有对照复用相同策略权重，并独立划分训练种子和测试种子。

## 资源约束

所有模型、数据、缓存和日志保存在数据盘。原始示教优先保存RGB、关节状态、末端位姿，不保存点云和深度。
首个任务不下载背景纹理库。正式长训练前先测小batch的显存、耗时和数据完整性。
不向任何外部平台上传实验数据、模型或训练日志。

## 固定执行长度基线

预测长度H保持模型配置，执行长度K取候选4/8/16；实际时间须依据测得控制频率计算。
后续协作监测器读取最新可部署观测。仿真接触和物体真值仅用于监督标签及评测。

## 已验证的工程链路

- 实际SAPIEN无界面RGB渲染通过。
- 成功采集一条handover_block专家示教；25Hz均匀采样，377个状态/动作对。
- 状态使用实际关节位置与实际夹爪开度；动作使用下一个采样点的指令目标。
- command targets另存于原始HDF5的commanded_state，后续可计算实际执行误差。
- 三路RGB数据经共享解码器转换为LeRobot v3格式；时间戳、维数、有限值检查通过。
- batch=8、20步SmolVLA微调通过，PyTorch峰值分配显存3.575GiB；仅单条数据流程检查。
- 检查点和归一化处理器重载通过，输出形状为1×50×14。
- 25Hz控制器回放专家动作成功完成交接；约14.56秒仿真时间。
- 模型与仿真分别运行于独立环境，通过权限0700目录中的本地Unix socket通信；10步闭环检查通过。

这些是工程验收，不是论文成功率。20步模型没有完成完整任务评测。

## 当前批次

`bash scripts/pilot_pipeline.sh` 顺序运行50条示教采集、数据校验转换、batch=8的2000步训练、K=4/8/16各3个未见种子评测。
每阶段有超时，出错立即停止；不无限重试，不自动重训，不自动关机。
所有K复用同一训练检查点，测试种子为1000–1002。

当前评测是同步调用、零模拟推理延迟的初始基线：推理墙钟耗时会记录，但推理期间仿真暂停。
它不能用于声称抗真实推理延迟。异步动作队列、延迟注入和事件监测器尚待实现。
目前只有方块交接的一种语言目标，不能据此声称语言泛化。
