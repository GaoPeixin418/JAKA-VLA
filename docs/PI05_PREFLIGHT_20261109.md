# π0.5 接入预检（2026-11-09）

## 已验证条件

- 服务器Ubuntu 22.04.4、单RTX 4080 SUPER；驱动报告32760MiB，PyTorch可见31.47GiB，预检时空闲约31.21GiB；系统内存58GiB，数据盘尚余约77GiB。GPU名称为4080 SUPER，并非4090。
- OpenPI源码固定在 `Physical-Intelligence/openpi@215abfb217dbac7d5f1273282331b9b1866c0479`，持久副本 `/data/jaka-vla/repos/openpi`；独立环境 `/data/pi05-env`，缓存 `/data/pi05-cache`。未改 `/data/jaka-vla/envs/vla`。JAX 0.5.3识别CUDA设备，PyTorch 2.7.1+cu126可识别GPU；官方 `pi05_libero` 配置可实例化。未装上游可选ALOHA/LIBERO子模块，也未训练π0.5。
- 官方README要求单卡推理显存>8GB、LoRA微调>22.5GB、全量微调>70GB，列出的数值是官方估计，不是Zu7实测峰值。32GB卡具备LoRA尝试空间，但余量需用实际batch和三相机测试；全量微调不在本卡预算内。
- 官方 `pi05_base/params` 已下载至 `/data/pi05-cache/models/openpi-assets/checkpoints/pi05_base/params`。GCS清单20个对象共12,441,721,931字节（约11.59GiB），本地20/20对象大小一致；实际恢复为51个参数数组、数组总字节数13,413,735,488，CPU进程峰值RSS 21,715,104KB，耗时16.37秒。这是**CPU权重恢复**，不是GPU推理或训练显存测试。缓存仅在租用服务器上，不等于GitHub备份；官方公开底模可重新下载。
- 本项目Zu7源数据为LeRobot 3.0：25Hz、14维实测state、14维下一采样点绝对关节/夹爪目标动作、三路RGB（头部/左腕/右腕）240×320。OpenPI固定的LeRobot依赖直接读取时寻找旧版 `meta/tasks.jsonl`，随后错误尝试访问Hugging Face并报401。`scripts/convert_zu7_for_openpi.py` 已从源数据生成独立兼容副本：`data/openpi/zu7_grasp_coverage_v21_pilot`为2条264帧，`data/openpi/zu7_grasp_coverage_v21_full`为8条1076帧。两副本都不上传Hub，源文件不改动；转换清单逐文件记录SHA256。完整副本经OpenPI读取器确认8条1076帧、25Hz，全部state/action逐帧数值完全相同；8条首末各一帧的三相机共48帧与源MP4解码像素完全一致。旧格式副本使用PNG保留已解码像素，源MP4本身是有损格式。
- `jaka_vla/openpi_zu7.py`实现Zu7三相机和14维动作变换。先将12个关节绝对目标转成相对实测关节的增量，两个夹爪开度仍为绝对量；反变换再加回关节状态并裁为14维。已用真实数据验证动作往返误差0。OpenPI的π0.5默认`action_dim=32`，模型前处理将14维state/action补为32维；真实样本已得到三路224×224 RGB、32维state、10×32动作块和200 token指令。不能简单把预训练权重层改成14维，不能借用UR5e双臂14维归一化统计。

## 下一步的有界验收

1. 为Zu7兼容副本计算独立的训练集归一化统计，审查近常量维度；模型服务与训练使用相同相机映射、增量关节/绝对夹爪语义。先在一个batch完成实际参数加载、前向和反向，再报告真实GPU显存峰值与用时。LoRA冻结条件需明确包含π0.5主干和动作专家；不能把官方`pi0`低显存示例原封不动套到`pi05`。
2. 最小验收通过后，在同一Zu7示教、固定开发种子上做有界LoRA实验；SmolVLA、π0.5使用相同仿真任务、控制器、抓取成功定义和独立保留的最终测试种子。模型大小不同，须同时报告数据规模、可训练参数、GPU时间和峰值显存。小样本训练损失不能代替闭环成功。
3. 扩场景先以少量多物体/多指令专家回放验证数据质量，再生成分层覆盖的数据。相同视觉场景给可区分的目标指令，并留出物体位置、干扰物布局和新组合；否则无法检验语言模态的必要性。现有单红块、单句指令不能支持语言理解结论。

本轮π0.5完成环境、权重缓存恢复和数据/前处理接口预检，没有Zu7模型前向、反向、微调、抓取演示或性能提升结果。SmolVLA仍是当前可运行基线；待一个真实batch的GPU验收后才比较模型规模。
