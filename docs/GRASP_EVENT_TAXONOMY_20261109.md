# 配对抓取的事件时序分类（2026-11-09）

对已保存的15条开发轨迹做离线分析；没有新训练、仿真回合或控制器改动。脚本 `scripts/classify_matched_grasp_events.py` 读取配对证据、逐控制步末端/物块轨迹、逐物理步持物证据和接触日志，并逐条核对轨迹SHA256、闭爪步与原成功判据。结果在服务器 `results/zu7_matched_event_labels_20261109_v2.json`。初版 `_20261109.json` 将方块三维位移与此前水平位移指标混用；v2统一为水平位移，保留初版记录以供追溯。

分类优先级：已连续有效持物0.6秒为`verified_grasp`；否则未请求闭爪为`no_close_before_budget`；否则闭爪前水平位移达到20mm为`object_displaced_before_close`；其余闭爪时原始目标TCP水平偏差达到40mm为`off_target_at_close`；剩余为`failed_close_near_target`。20mm/40mm是描述性分析阈值，不是训练标签或机器人在线控制规则。方块位置与接触来自仿真真值，不能输入策略。成功轨迹也可能在闭爪前出现物体位移，因此“先移动”不能直接解释为失败因果。

| 检查点 | 有效抓取 | 未闭爪 | 失败且闭爪前位移≥20mm | 失败且闭爪时偏差≥40mm | 近目标闭爪仍失败 |
| --- | ---: | ---: | ---: | ---: | ---: |
| stable1500 | 0 | 0 | 4 | 1 | 0 |
| coverage3000 | 2 | 0 | 2 | 1 | 0 |
| recovery4000 | 2 | 1 | 1 | 1 | 0 |

具体地，stable1500的204/205/206/207在首次闭爪前方块水平移动约175/37/30/153mm；203仅移动约10mm但原始目标仍偏87mm。coverage3000的失败205/206先移动约74/81mm，203无明显移动但偏65mm。recovery4000的205在预算内未闭爪，方块水平移动约868mm；206先移动约145mm；203仅移动约12mm但偏44mm。两组成功都是204、207。各事件的精确时刻、首次接触与轨迹校验见JSON。

此分类提示示教采样和诊断需要同时覆盖“空中目标偏离”和“过早物体交互”，并单独审查长时间不闭爪案例。闭爪时偏差可能是提前碰移方块后的结果，不能把它当成纯视觉定位误差；接触日志记录的首次接触也未必是有效双指夹持。当前只有5个配对种子、单一红色方块和固定指令，不能支持论文统计结论、语言泛化或Sim2Real结论。
